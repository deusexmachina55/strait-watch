Destination and schedule

Keep daily, weekly (Sundays), monthly (1st)

The service runs as the local user svc-straitwatch. A local drive folder must give that user Modify rights (setup.ps1 does not do this for folders outside the repo; grant it with icacls "D:\Backups\strait-watch" /grant svc-straitwatch:(OI)(CI)M from an admin prompt). A UNC path on the NAS needs a NAS user with write access to that share: add BACKUP_SMB_USER and BACKUP_SMB_PASS to .env and restart the service. A local snapshot is always written to data\backups\ first (last 3 kept), then copied. Restore: stop the service, replace data\strait.db with a snapshot, start the service.
